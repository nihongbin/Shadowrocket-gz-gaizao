S5 中美双市场规则

中国常用 App 优先使用本地 DNS 和直连规则；海外账号、AI、流媒体、测试站和未知流量交给代理兜底。

下载配置 查看最新版本

公开模板不包含节点、订阅、账号或代理组。

中国 App 本地 DNS + DIRECT 微信、淘宝、抖音等确认域名
S5 规则判断
海外与未知 PROXY YouTube、TikTok、AI 与测试站

使用前提

你需要已经安装 Shadowrocket，并在其中配置了可用节点或订阅。S5 只提供 DNS、分流和 Host 规则，不提供代理服务。

核心作用

兼顾本地体验与海外访问

01

中国 App 优先直连

确认过的中国域名同时配置 Host 与 DIRECT，减少常用页面绕路。

02

海外流量代理兜底

海外账号、AI、流媒体、测试站和未识别域名优先交给代理。

03

规则更新先审核

第三方规则变化先报告、再确认和测试，不会直接改变手机规则。

安装方法

四步开始使用

  1. 准备节点确认 Shadowrocket 中已有可用的美国节点或订阅。
  2. 获取配置下载 `.conf` 文件，或点击“复制导入链接”。
  3. 导入并选中在 Shadowrocket“配置”页面导入 S5，并选择使用该配置。
  4. 重新连接将“全局路由”设为“配置”，断开后重新连接。

安装后验证

分别检查中国和海外场景

固定同一个节点和网络，切换配置后断开并重新连接 Shadowrocket。

中国 App代表域名应命中 DIRECT，图片和视频页面正常加载。
海外 AppYouTube、TikTok、ChatGPT 核心域名应命中 PROXY 或 FINAL,PROXY。
DNS 辅助检查测试站主域名应命中 PROXY；中国白名单使用中国 DNS 不单独视为失败。
